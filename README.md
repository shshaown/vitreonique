# Vitreonique

A personal interactive design portfolio by Sajjad Hossen Shaown. Independent of Aliq and other business accounts.

Six pages: home, work, case study, studio, contact, and the interactive 3D experience. Includes a custom 404 page.

## Local preview

Run `python3 -m http.server 8766 --directory site` and open http://localhost:8766.

No build step or package installation is needed. Three.js is vendored with its MIT license. Fonts load from Google Fonts, with system fallbacks.

## Deployment

GitHub Pages deploys the `site` folder through `.github/workflows/pages.yml`. Repository visibility must remain **private**; the website is intended to be **public**. GitHub must support Pages for private repositories on this account’s plan.

## Content

Vitreonique GX-8 is a self-initiated visual concept inspired by a robotic octopus reference, not a commissioned client engagement or verified engineering product. The model and internal details are procedural interpretations. No performance claims or testimonials are implied.

The contact form opens a mailto draft; it does not send or store submissions. The website has no analytics, account system, database, or chat records.

Vitreonique is a coined project name. An exact-name web search returned no results when checked on 2026-11-11; universal uniqueness, domain availability, and trademark rights are not established.
